## [1.0.0] - 2026-08-18

First public release. Built with [Avalonia](https://avaloniaui.net/) on .NET 10,
for Windows and Linux.

### Added

- Practice timer with an adjustable block length from 30 seconds to 10 minutes
  in 10-second steps, defaulting to 3 minutes.
- Automatic 3-minute cooldown when a practice block ends, locked against being
  skipped for its first 60 seconds, with **Reset** and the duration slider
  disabled for its full length.
- Two-note end-of-block chime (G5 → C6), generated as a WAV by `make_chime.py`
  and played through miniaudio, so it works on every platform. Every failure
  path is swallowed: with no usable audio device the colour change is still a
  complete signal.
- Full-window colour cross-fade between the practice and cooldown palettes over
  550 ms, built on Avalonia `BrushTransition`s.
- Circular progress dial drawn as a `StreamGeometry` arc sweeping clockwise from
  12 o'clock.
- Drift-free timing based on a stored UTC deadline rather than accumulated
  ticks, so a stuttering UI thread or a suspended process cannot lose time.
- Keyboard control: `Space` to start, pause, resume or skip an unlocked
  cooldown; `R` to reset; `Esc` to close.
- Frameless rounded window with custom chrome, drag-to-move and a drop shadow.
- `GuitarPracticeTimer.Core`, a dependency-free project holding the timer state
  machine, dial geometry and palettes, covered by 33 tests concentrated on the
  cooldown enforcement rules.
- `GuitarPracticeTimer.Ui`, the shared Avalonia view and view model, so future
  mobile builds reuse the same rules and layout rather than reimplementing them.
- Multi-size application icon generated by `make_icon.py`, and
  `verify_assets.py`, which checks both generated assets still match their
  generators by content rather than by byte comparison.
- Trimmed, compressed, self-contained single-file builds: about 32 MB for
  win-x64 and 30 MB for linux-x64, with no runtime to install.
- Continuous integration building and testing on Windows and Linux, and releases
  carrying a build provenance attestation and `SHA256SUMS.txt` so a download can
  be traced to the source and workflow that produced it.
- Repository documentation: `LICENSE` (MIT), `CONTRIBUTING.md`,
  `CODE_OF_CONDUCT.md`, `SECURITY.md`, `FUNDING.yml`, issue and pull request
  templates, and this changelog.
